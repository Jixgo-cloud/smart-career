1.ความสำคัญและที่มา
การคัดกรองทักษะสายเทคโนโลยีในปัจจุบัน
การสมัครงานสายเทคโนโลยีในปัจจุบันมักอ้างอิงจากคำกล่าวอ้างทักษะบนเรซูเม่ เช่น React, Node.js หรือ SQL ซึ่งทั้งหมดนี้ต้องอาศัยหลักฐานเชิงประจักษ์จากการลงมือเขียนโค้ดและโปรเจกต์จริงจึงจะวัดความสามารถได้ถูกต้อง
บทบาทของเทคโนโลยีในปัจจุบัน
ปัจจุบันมีแพลตฟอร์มประกาศงานออนไลน์ ระบบ GitHub สำหรับเก็บซอร์สโค้ด ระบบตรวจโค้ดอัตโนมัติ และคอร์สเรียนออนไลน์ที่ช่วยสนับสนุนการเตรียมความพร้อมสู่อาชีพสายไอที
ปัญหาของแพลตฟอร์มที่มีอยู่ในปัจจุบัน
ในปัจจุบันแม้จะมีเว็บไซต์หางานและเว็บฝึกเขียนโค้ดอยู่หลายตัว แต่แต่ละระบบแยกส่วนกัน เช่น เว็บหางานไม่มีระบบตรวจโค้ดจริง ส่วนเว็บฝึกโค้ดไม่ได้เชื่อมกับประกาศงานจริงในตลาด ผู้ใช้จึงต้องสลับใช้งานหลายระบบ
ปัญหาการเตรียมความพร้อมของผู้ใช้งาน
นักศึกษาจบใหม่หรือผู้หางานสายไอทีบางกลุ่ม อาจไม่ทราบว่าตนเองยังขาดทักษะใด (Skill Gaps) เมื่อเทียบกับเกณฑ์ของบริษัท และเมื่อไม่ผ่านการคัดเลือกก็ขาดแผนพัฒนาทักษะและคอร์สเรียนที่ตรงจุด

2.วัตถุประสงค์
เพื่อพัฒนาระบบรวบรวมประกาศงาน วิเคราะห์บริบทโครงการจาก GitHub และจับคู่งานสายเทคโนโลยี
เพื่อพัฒนาระบบจัดสอบเขียนโค้ดอัตโนมัติและสกัดทักษะด้วย AI พร้อมแนะนำคอร์สเรียนและแผนพัฒนาทักษะ
เพื่อประเมินผลการทำงานและความพึงพอใจของผู้ใช้งานที่มีต่อระบบ SMARTCAREER

3.ขอบเขตงานวิจัย
1.ขอบเขตด้านผู้ใช้งานของระบบ
  • ผู้เยี่ยมชมสามารถค้นหาตำแหน่งงาน คอร์สเรียน ดูรายการข้อสอบกลาง และทดลองวิเคราะห์โปรไฟล์ GitHub สาธารณะได้
  • ผู้สมัครงานสามารถเข้าสู่ระบบด้วย GitHub OAuth เพื่อซิงก์ข้อมูลโครงการและภาษาที่ใช้พัฒนาได้สูงสุด 8 repositories
  • ผู้สมัครงานสามารถทำแบบทดสอบทฤษฎีและเขียนโค้ดปฏิบัติ พร้อมดูกราฟเรดาร์ทักษะ 5 หมวดหมู่ได้
  • ผู้สมัครงานสามารถดูเปอร์เซ็นต์การจับคู่งาน (Match Score) กดสมัครงาน และติดตามสถานะใบสมัครได้
  • ผู้สมัครงานสามารถดูช่องว่างทักษะ (Skill Gaps) แผนพัฒนาทักษะ และคอร์สเรียนแนะนำจาก Udemy และ YouTube ได้
  • บริษัทสามารถเข้าสู่ระบบด้วย Google OAuth ส่งเอกสารยืนยันนิติบุคคล 13 หลัก สร้างประกาศงาน และออกข้อสอบบริษัทได้
  • บริษัทสามารถคัดกรองผู้สมัคร มอบหมายข้อสอบ บันทึกผลประเมินผู้สมัคร 4 มิติ และส่งออกรายชื่อเป็นไฟล์ CSV ได้
  • ผู้ดูแลระบบสามารถอนุมัติบริษัท จัดการผู้ใช้/ทักษะ/ข้อสอบกลาง สั่งดึงข้อมูลงานและคอร์ส และตรวจสอบ Audit Logs ได้

3.ขอบเขตงานวิจัย
2.ขอบเขตด้านฟังก์ชันของระบบ
  • รวบรวมประกาศงานจากแหล่งภายนอก 5 แหล่ง (JSearch, JobsDB, Blognone, JobThai, Remotive) และงานตรงจากบริษัท
  • สกัดทักษะทางเทคนิคจากประกาศงานอัตโนมัติด้วยคลังคำสำคัญร่วมกับโมเดล Google Gemini AI
  • วิเคราะห์บริบทโครงการจาก GitHub API ทั้งสัดส่วนภาษา ป้ายกำกับ (Topics) และไลบรารีจากไฟล์ package.json
  • จัดสอบเขียนโค้ดออนไลน์ผ่าน Monaco Editor และตรวจชุดทดสอบ (Test Cases) อัตโนมัติด้วย Judge0 Sandbox
  • คำนวณคะแนนความเหมาะสมกับตำแหน่งงาน (Match Score) ถ่วงน้ำหนักทักษะจำเป็น 70% และทักษะเสริม 30%
  • แสดงกราฟเรดาร์ทักษะ 5 มิติ ได้แก่ Frontend, Backend, Database, DevOps และ Testing
  • วิเคราะห์ช่องว่างทักษะตามสายอาชีพเป้าหมาย และสร้างแผนพัฒนาทักษะ 3 ขั้นตอนจากผลประเมิน 4 มิติของบริษัท
  • ซิงก์ข้อมูลประกาศงานและคอร์สเรียนพร้อมปิดประกาศที่หมดอายุอัตโนมัติทุกวันเวลา 00:00 น. (Cron Scheduler)

3.ขอบเขตงานวิจัย
3.ขอบเขตข้อจำกัดของระบบ
  • การทำงานของระบบจำเป็นต้องเชื่อมต่ออินเทอร์เน็ตในการยืนยันตัวตน OAuth การซิงก์ข้อมูล GitHub และการประมวลผลข้อสอบ
  • การกดส่งใบสมัครและติดตามสถานะภายในระบบรองรับเฉพาะประกาศงานที่บริษัทสร้างในระบบ (INTERNAL) ส่วนงานจากเว็บภายนอกจะเป็นการเปิดลิงก์ไปยังเว็บไซต์ต้นทาง
  • การดึงประกาศงานจากเว็บไซต์ภายนอกบางแห่งอาจถูกจำกัดด้วยระบบป้องกันบอท จึงต้องใช้กลไกสำรอง HTTP/2, Puppeteer หรือการนำเข้าผ่านไฟล์ Local Job Batch
  • ระบบเรียกใช้งาน API ภายนอกแบบมีโควตา (เช่น Gemini AI, Judge0, JSearch, YouTube API) ซึ่งมีข้อจำกัดด้านจำนวนครั้งในการเรียกใช้งาน
  • ระบบรันและตรวจโค้ดอัตโนมัติในห้องสอบปฏิบัติรองรับภาษา JavaScript (Node.js) และ Python เป็นหลัก
